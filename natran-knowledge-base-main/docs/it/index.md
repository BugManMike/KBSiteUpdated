# IT

Tools, accounts, telephony, devices, and how to get help with them.

Google Workspace is the identity spine — Windows sign-in, Microsoft access and Keeping all
derive from it — ManageEngine Endpoint Central manages Windows devices, and Jamf Now manages
Apple devices.

* [Automation](automation/) - Workflow automation on the self-hosted n8n instance: email → Google Chat notification pipelines.
* [Devices](devices/) - Windows, Apple and Chrome device management: enrollment, configurations, local accounts, software deployment, and peripherals.
* [Google Workspace](google-workspace/) - Identity, mail and collaboration: account provisioning and offboarding, 2FA, email signatures, shared inboxes, and Context-Aware Access.
* [Network](network/) - Internal office networking on the UniFi Dream Machine Pro: door access and the Raspberry Pi software repository.
* [Printers](printers/) - Brother MFC printer setup, fixed IP assignment, ManageEngine deployment, and scan-to-Drive.
* [Telephony](telephony/) - CallTrackingMetrics, plus RingCentral material of unconfirmed status.
