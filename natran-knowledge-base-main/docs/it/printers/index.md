# Printers

Brother MFC printers, wired only, deployed to work devices through ManageEngine. Setting up a
new printer end to end means working through the first three of these in order.

* [Brother printer setup](brother-printer-setup.md) - Unboxing and configuring a new Brother MFC printer: cabling, inventory, web sign-in, auto-updates, and restriction settings.
* [Printer fixed IP assignment](fixed-ip-assignment.md) - Reserving a static IP in UniFi and pinning the same address on the device so ManageEngine can deploy it.
* [ManageEngine printer deployment](manage-engine-deployment.md) - Creating an IP Printer configuration in Endpoint Central, including which driver INF file to pick.
* [Brother scanner to Google Drive](brother-scanner-to-drive.md) - Registering a printer with Brother Web Connect so scans upload to a chosen Drive account.
